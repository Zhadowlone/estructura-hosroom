# Hosroom Estructuras

Programa de escritorio para Windows de Hosroom · Estructuras de tarifas.

## Instalar

1. Entra a [Releases](https://github.com/Zhadowlone/estructura-hosroom/releases/latest) y descarga `Hosroom-Estructuras-Setup-X.Y.Z.exe`.
2. Ábrelo. Si Windows muestra «Windows protegió tu PC», elige «Más información» > «Ejecutar de todas formas».
3. Entra con la clave de tu equipo.

Las actualizaciones se descargan solas y se instalan al reiniciar el programa.

Este repositorio solo publica los instaladores. El código no está aquí.
